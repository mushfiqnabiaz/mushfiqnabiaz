About me

I'm a Product Manager who also owns the DevOps and infrastructure side of what I ship — CI/CD pipelines, cloud infrastructure, and production monitoring — rather than handing it off. I lead IoT and SaaS product delivery in production across multiple districts, and I build my own tools when I see a gap worth closing.

🔭 Currently leading product, DevOps, and infrastructure at Aqualink Bangladesh Limited — IoT and SaaS systems for aquaculture, cold storage, and energy monitoring.
🛠️ Founder and solo builder of Infradock — a server control panel and infrastructure operations platform, now in public beta.
🌐 Comfortable down at the network layer too — Layer 2 protocols, load balancing, DNS, and VPN/firewall configuration.
🌱 Sustainability-minded: my work has cut spoilage, energy use, and water consumption across IoT deployments aligned with the UN SDGs.
What I'm building — Infradock

infradock.cloud is a server control panel and infrastructure operations workspace where teams monitor servers, open browser-based SSH, manage files, and control services — all from one place. I designed and built the core platform (SSH terminal access, remote systemctl control, an SFTP file explorer, RBAC, SSL certificate expiry monitoring) and I run its production infrastructure and CI/CD pipeline solo.
